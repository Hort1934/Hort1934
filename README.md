## About me

I'm a software engineer from Kyiv. Most of my work is Python on the back end: APIs, event-driven services and data processing.

Right now I build software for robotic systems: real-time video pipelines (RTSP/UDP, FFmpeg), computer vision and control tools for multi-sensor hardware. In my spare time I work on ChannelSense, an AI analytics bot for Telegram communities on TON, and take part in hackathons.

Open to collaboration on backend, computer vision, robotics and AI projects.
